zhl主题的hexo个人网站搭建

这算是第二次搭建个人网站了，主要是前一次的默认主题不太满意。这次搭建的大部分基础环境应该是具备的，所以并不算是从零开始搭建。

搭建流程

使用管理员身份运行git-bash，进入到需要安装的目录，然后按照hexo的readme里面的要求，执行npm install hexo-cli -g，npm install hexo --save，就能设置好环境。

hexo init test可以在当前目录下再次创建一个叫test的目录，其中会安装hexo运行需要的所有内容。

从https://github.com/lizehongss/hexo-theme-zhl上面下载压缩包，然后把解压缩出来的文件夹放到`test`目录中的`theme`文件夹中，并修改名称为`zhl`，再运行`hexo s`启动服务器，即可在localhost:4000上面看到网页的内容了。

hexo deploy配置

hexo deploy可以把本地的文件上传到github上面，但是需要进行一定的配置才能使用，主要需要配置ssh的密钥。

首先在windows本地配置ssh密钥：

此时，能够看到cat命令显示出来的密钥的具体信息，复制下来。然后登录github，点击个人头像，选择settings，然后在SSH and GPG keys选项处点击new SSH key，title随便写，key type默认，key上面黏贴复制的密钥的内容，然后点击add SSH key，即可配置成功。

在执行前，还需要在目录下安装git工具：npm install hexo-deployer-git --save
